# 浆果病虫害防治专家手册

## 1. 草莓白粉病 (Powdery Mildew)
- **病征**: 叶片或果实表面覆盖一层白色的粉状物，严重时导致叶片卷曲。
- **防治方案**: 
  - 改善通风透光，降低环境湿度。
  - 使用 15% 三唑酮可湿性粉剂 1500 倍液喷雾。
  - 安全间隔期：7-10 天。

## 2. 蓝莓蚜虫 (Aphid)
- **病征**: 嫩叶背部集结绿色小昆虫，导致嫩芽萎缩。
- **防治方案**:
  - 利用天敌如瓢虫进行生物防治。
  - 药剂推荐使用 10% 吡虫啉可湿性粉剂 2000 倍液。

## 3. 灰霉病 (Gray Mold)
- **病征**: 浆果表面出现灰色霉层，果实软腐。
- **防治方案**:
  - 及时清除病残体，集中销毁。
  - 喷施 50% 腐霉利可湿性粉剂 1000 倍液。
